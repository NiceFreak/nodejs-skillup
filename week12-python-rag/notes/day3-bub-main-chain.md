## 5. 下午：三条主链

只跟以下主链，其余按 §2 与周计划 §7 顺序砍：

- [ ] **turn lifecycle**：一次 turn 从触发到结束经过的函数序列；中间状态存放在哪个对象；异常与取消
  路径各自在哪一层被捕获。
- [ ] **tape 追加**：追加了哪些事件类型；追加发生在模型/工具调用之前还是之后；事件是否可变、是否有顺序保证。
- [ ] **context rebuild**：session 依据 tape 重建 context 的入口函数、输入输出类型，以及是否存在裁剪、
  截断或去重策略（只记录源码写明的部分，未写明的记为待验证）。
- [ ] **model / tool / harness 职责边界**：谁决定调用哪个工具、谁执行、谁把结果写回 tape；错误与重试
  归属哪一层；harness 对 model 与 tool 的调用是同步还是异步。
- [ ] **hook（仅主链经过部分）**：注册发生在什么时机、被调用在主链的哪一步、能改写哪些输入或输出；
  未被主链经过的扩展点不追。

Python 语法在此处按需现场展开（白名单）：typing/Protocol、async/await 与 `async with` 的读法只解释
到「读懂这段调用链」为止，不做语法通览。
