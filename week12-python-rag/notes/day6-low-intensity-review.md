## 2. 题库作答契约

1. 每题由本人独立先答：不运行代码、不查文档、不问 AI；先写预测和理由。
2. 每题至少包含“输出或行为”“为什么”“与 JS/TS 的对应边界”三项；Q10 三个子问题分别作答。
3. 不确定处直接标 `不确定`，不靠模糊措辞伪装结论。
4. 答完一题即当场 review；review 结论与讲解由 AI 按文案规范回填进题库该题之下，追问沉淀到文档合适位置。
5. review 按题逐项区分：正确、部分正确、事实错误、类比过强、待运行验证。修改版保留原答与修正差异。

本题库不是新的 DEBT 重建。若 review 只暴露 Python 语法/API 记忆缺口，按白名单查证即可；只有出现
黑名单知识的 L2 援助或重建卡档，才按 `AGENTS.md` 记债。

- **跨语言迁移应比较运行语义，不只比较相似语法。** D6 暴露的偏差主要落在求值时机、参数绑定、

  结果校正成立条件。

  复用于 W13-W16 的 Python 脚本。

  基线与当前任务能力；D6 的基础题偏差说明这些证据不能扩大为“已全面掌握 Python”。题库记录的 27 条
  错误表述也不等于 27 个独立知识缺口，其中多条来自同一底层规则。
