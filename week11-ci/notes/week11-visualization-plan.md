## 1. 这份方案要解决的问题

D1 产出的是一份 760 行、18 条决策、五张表的契约。它自洽、可执行，但有三个缺口是文字形态天然填不上的：

1. **「谁在哪一侧执行」与「失败了会怎样」是同一条线，而契约把它们拆在两张表里。**
   契约 §5.1 的第 2 列（在哪一侧）与第 5 列（失败时服务器处于什么状态）读起来是两件事；
   实际上前三阶段之所以零影响，正是因为它们**不在服务器那一侧**。这条对应关系是本周最核心的心智，
   现在要读者自己在两列之间连线。

2. **契约里最贵的三条，是「两条各自合理的条款合起来是错的」——而它们散在四个地方。**
   B1（controller 侧 `npm ci --omit=dev` 会砍掉 jest）、B2（`logger` 谁都能打，标记不能承担信任）、
   B3（nodeapp 是 nologin，SSH 唯一入口是 ubuntu），加上 wrapper 位置参数被 `command=` 吞掉、
   openjdk 17→21 的事实修正，分别落在 Q4 / Q9 / Q14 的答案里、契约 §4.1 的自查行里、
   `day1-contract-freeze.md` §3 的偏差表里、`day2-controller-setup.md` §2.1 的修正注里。
   **它们是同一族的**：纸面推演抓到的、机器抓不到的、换任何一套 CI 工具都还会再犯一次的。

3. **本周有一批「已经决定、但还没有对象」的格子，文字写不出它们离真实还差多远。**
   越权验证的两条输出、bcrypt 在服务器侧走预编译还是走编译、`systemctl restart` 的实际不可用时长、
   回滚三条路径里哪一条真的走过——全是 D3 / D4 才有的。**这正是 `contract` 档位存在的理由**，
   而板头计数会把「这块板现在还是一张纸」这件事诚实地写在最上面。

本方案不发明新语法，只做一处扩展（§3.2 的「两侧」空间约定），骨架仍是 **契约 → 实测 → 差在哪**。

## 5. 板块设计（七块，每块只回答一个问题）

> 每块后面标了**最早开工日**——这是本方案里最实质的一列，理由见 §10。

### ① 三条自动化，一把钥匙（`topic=lanes`）· 最早 D5

**空间编码**：从一次 `git push` 出发的三条并排轨道——GitHub Actions / Jenkins / W9 手工发布——
各自止步在不同位置；右侧服务器画成一个**只有一个入口**的盒子，只有 Jenkins 那条轨道上挂着钥匙并接进去。

**一眼结论**：三条自动化跑着同一份测试，**能写服务器的只有一条**。
Actions 红了不影响部署，这是拍板过的决策（Q3），不是漏配——写在轨道终点旁边，
否则第一次出现「Actions 红但部署绿」时会被当成 bug。

**第二条结论（轮询那一段）**：整条链只有这一段不是事件驱动的，画成一段带刻度的等待段（上限 5 分钟）。
webhook 走不通是**网络位置**决定的，不是配置——这一句紧贴着画。

**为什么排最后**：三条轨道里 Jenkins 那条的终点位置在 D2（止于 Test）与 D3（延伸到 Deploy/Verify）**各不相同**，
D5 之前画哪一版都会当天过时。

### ② 五阶段：哪一阶段能把服务器弄坏（`topic=stages`）· 最早 D2 收口后 —— 建议第一批

**空间编码**：五阶段横排在「两侧」约定上（前三阶段整段在左半，第 4 阶段跨中线，第 5 阶段发起在左、目标在右）；
每阶段下面一条「服务器状态」轨道。

**一眼结论**：五个阶段里**只有一格是「可能中间态」**，而它恰好是唯一跨过中线的那一阶——
**在哪一侧执行，和能造成什么后果，是同一条线**。前三阶段的服务器状态是一整段连续的「未被碰过」，
不是三段各自写「未动」。

**第二条结论（失败后的动作有三种，不是一种）**：人工介入（阶段 1–3）/ 自动回滚（阶段 4）/
**已部署且不自动回滚，人工判定**（阶段 5）。第三种最容易被读错——画成一个停在服务器侧、等人来按的终点。

**档位**：D2 收口后，阶段 1–3 是 `measured`（构建记录里看得到装了什么、跑了哪些测试），
阶段 4–5 仍是 `contract`；每一格 contract 必须写清**证据差在哪**（沿用 W10 的 `caveat` 纪律，
档位标签一个词带不过去）。

### ③ 信任边界：从全权免密到两道闸门（`topic=trust`）· 最早 D3 收口后

**空间编码**：一个身份 `ubuntu`，两条并排通道（个人密钥 / 部署密钥），每条通道上串两道闸门
（`authorized_keys` 的 `command=` / `sudoers` 白名单），闸门下面挂它各自拦住什么。
左右两半是前后对照：**现状**（8/24 实测 `sudo -l`：四行全权免密）→ **收窄后**（两行四条白名单 + 三条 wrapper 命令）。

**一眼结论**：两道闸门管的**不是同一件事**——一道管「这把钥匙进来能执行什么」，一道管「这个用户能提权做什么」；
只装一道各自会漏哪一类，用两条穿过闸门的轨迹画出来。

**必须紧邻的一条（F1 的代价）**：收窄的不是部署密钥，是**整个 ubuntu 身份**——
个人密钥登录后的手工运维（`journalctl` / `nginx -t` / `tail`）也会一起被挡住，要用先加白名单。
这一条不写在图旁边，D3 当天第一次被拒时会被当成配置错误去「修」。

**档位**：现状那半是 `measured`（块 C 实测）；收窄后那半到 D3 越权验证的两条输出落地才翻档。
**在此之前，这块板上「被拒」的那两个格子是空的**——空格本身就是「还没验证过」的形态，不补。

### ④ 回滚：三条路径，两个指针（`topic=rollback`）· 最早 D4 收口后

**空间编码**：一条提交时间线上放两个指针——`.rollback_target`（本轮部署开始时的快照）与
`.previous_commit`（最近一次验证通过的版本）；三种失败发生在链路的不同位置，箭头各自回到不同的指针；
第三条路径（回滚动作本身失败）**没有目标**，画成断在半空的箭头。

**一眼结论**：**正常时两个指针指着同一处，所以最容易被合成一个文件——而它们分开的那一刻，正是需要回滚的那一刻。**

**第二条结论**：回滚不是切一个指针，是**重跑一次旧版本的完整部署**（`git reset` + `npm ci` + restart）——
因为形态选的是原地更新。「逻辑原子性」不等于原子切换，这两个词的差别就是这块图与一张 symlink 切换图的差别。

**必须紧邻的一条**：首次基线 `.previous_commit = 6a1b1a1` 是**未经部署后验证的 commit**（W10 收口态没有这一步），
它只是「当前唯一已知可用态」。这个限定语一旦被抹掉，回滚看起来就是闭环的。

**为什么排到 D4 之后**：三条路径在 D4 之前只有一条会被真的走过；三条画得一样粗，就是把两条预测画成了实测。

### ⑤ 部署后验证：七项各自证明不了什么（`topic=verify`）· 最早 D3 收口后 —— 与 ⑥ 并列的代表页

**空间编码**：七项验证 × 五层覆盖（进程存活 / socket 绑定 / HTTP 路由 / DB 可连 / 对外反代语义）的矩阵，
最右一列是每项**「它证明不了什么」**——这一列是本块的重心，不是备注。

**一眼结论**：**没有任何一项能单独证明一次部署成功**；`/health` 只覆盖一层，
而覆盖「对外反代语义」那一层的**只有一项**（公网 curl）——那一格只有一个点，删掉它整层就空了。
这正是 W10 盲区②在本周被补上的方式。

**第二条结论（仍有覆盖不到的）**：`/admin/` 静态面没有任何一项验证碰得到（Q15 明写）；
「进程活着但没绑定」只有 `ss` 那一项兜得住，而它的根因到 D4 才复现——**那一格标 `pending`，不标绿**。

**为什么它可迁移**：换掉 Jenkins、换掉 Node，这张表的形状不变——**每加一项检查，都要同时写下它证明不了什么**。

### ⑥ 契约自查抓到的三条（`topic=selfcheck`）· **现在就完整，D2–D5 不会再改** —— 代表页，建议先做

**空间编码**：纠错三段式（❌ 原以为 → ⚡ 实际机制 → ✅ 修正），六行；最右一列**「谁抓到的」**。

| # | 原以为 | 实际机制 | 谁抓到的 |
|---|---|---|---|
| B1 | `npm ci --omit=dev` 装一次就够 | controller 侧要跑测试，jest / supertest / MMS 都在 devDependencies | 冲突自查（Q5 × Q6） |

**最值钱的一行是 B2**，因为它换栈仍成立：**一个谁都能伪造的标记，不能承担信任**。

### ⑦ 与手工部署的对照：哪几步没被替掉（`topic=handoff`）· 最早 D5

**空间编码**：W9 手工发布的六步 × 三种归属——**被流水线替掉 / 仍需人执行 / 本周明确不交给自动化**。

**第三格（controller 在开发机的代价）**：关机 / 休眠即流水线不存在——这条按 Q1/Q2 显式接受过，
