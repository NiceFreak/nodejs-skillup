## 走查 · 逐句提词（对着链路图的编号讲，约 2–3 分钟）

> 编号 ①–⑥ 与前端展板那张链路图一一对应，讲的时候手指跟着编号走。每条是提词、不是逐字稿，
> 都是已发生的事实；怎么展开、加什么个人体会由本人临场。

- **开场（定位）**：这是零后端的学习展板，发布在 GitHub Pages 的子路径上，手机就能复习。
- **① 前端源码**：同一份 week8 前端，源码里前台后台都有——今天只发其中**零后端的那部分**。
- **② 构建开关**：`VITE_SHOWCASE_ONLY=1` 把需要后端的管理后台切掉，`--base=/skillup-week8/` 指定子路径。
  停一下点明**为什么切**：Pages 是纯静态托管，跑不了 Express/Mongo，后台真链路上不了。
- **③ 构建产物**：`vite build` 出一堆静态文件 `dist/`（HTML/JS/CSS）；到这一步就和"服务器"没关系了。
- **④ 拷贝到 Pages 仓**：把 `dist` 放进 `nicefreak.github.io` 的 `skillup-week8/`。
- **⑤ 合并 main**：**关键点**——推分支不上线，PR 合并进 `main` 才触发发布（这条坑值得单独讲一句）。
- **⑥ 上线**：Pages 构建约 1 分钟，子路径 URL 生效；用 hash 路由，所以刷新不 404。
- **收尾（沉淀）**：这条链路固化成了 `deploy-showcase-pages` 技能，下次一句话就能复用——把过程变成能力。

## 关键决策点（讲到每个岔路口的取舍）

| 决策 | 为什么 | 证据 / 落点 |
|---|---|---|
| 只发布**零后端展板**，排除管理后台 | Pages 是纯静态托管，跑不了 Express/Mongo | `VITE_SHOWCASE_ONLY` 隐藏 `#/admin`、导航、页脚 |
| 放在**子路径** `/skillup-week8/` | 与已有 `/viz/`、`/screenplay/` 并列，语义清晰 | `--base=/skillup-week8/` |
| 用 **hash 路由** | 子路径静态托管下 hash 路由天然无 SPA 刷新 404 | `App.tsx` 的 `#/showcase` |
| 笔记链接**改为板内跳转** | 相对 `.md` 链接在静态站点点不动；改切板对移动端最顺手 | `MarkdownNotes.tsx` 的 `a` 渲染器 |
| CORS **本地被 dev proxy 隐藏** | 本地同源转发，后端「零改动」；跨域部署才需 CORS | `vite.config.ts` proxy；后端上线属 backlog |
